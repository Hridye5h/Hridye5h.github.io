AlphaRank — ML Quant Trading System

Python · LightGBM · Walk-forward backtest

A systematic NSE equity system that computes ~50 point-in-time features on ~380 stocks and uses a multi-horizon (5/10/20-day) LightGBM model to rank stocks cross-sectionally each week, holding a risk-parity basket of the top 7 with volatility-adaptive stops, sector caps and a drawdown kill-switch. Validated with a cost-adjusted walk-forward backtest — and I caught and fixed a data-leakage bug that had inflated the Information Coefficient from a fake 0.48 to an honest ~0.01–0.02, then rebuilt it as a per-date Spearman rank IC. Paper-traded on free data with a live dashboard.

RepoSage — Agentic RAG for Codebases

Python · LangGraph · Qdrant · FastAPI

An agentic RAG assistant that answers natural-language questions about any codebase with file-and-line citations. Uses AST-aware chunking and hybrid retrieval (dense embeddings + BM25, fused via Reciprocal Rank Fusion) over a Qdrant vector store, plus a selective LangGraph self-RAG loop and an evaluation harness. Hybrid retrieval reached Mean Reciprocal Rank 0.81 (vs 0.60 BM25, 0.75 dense) with LLM-judged faithfulness 1.0 — directly relevant to modern agentic-AI and MCP-style tooling.

Facial Emotion Recognition — RAF-DB

PyTorch · DDAMFN + ConvNeXt-V2 · Grad-CAM

Multimodal Product Tagging — CLIP

PyTorch · CLIP · Vision-Language

A CLIP-based multimodal model that auto-tags products with 4 catalog attributes (category, colour, gender, season) from image + title in a single forward pass — 92% mean accuracy (category 98%, gender 99%) across 30K products. Quantified robustness to missing metadata: with titles removed, mean accuracy holds at 82% as the model falls back on CLIP image features. Deployed as a live Gradio demo.
